# 📄 BookTune Presentation Page

Cette page contient la présentation marketing de BookTune, prête pour hébergement sur GitHub Pages.

## 🌐 Activation de GitHub Pages

### Étape 1 : Aller dans les paramètres du repository
1. Ouvrir https://github.com/Jean-bassene/booktune
2. Aller dans **Settings** → **Pages**

### Étape 2 : Configurer la source
- **Source** : `Deploy from a branch`
- **Branch** : `production` / `docs` folder
- **Save**

### Étape 3 : Attendre le déploiement
- GitHub va déployer automatiquement la page
- URL finale : `https://jean-bassene.github.io/booktune/`

## 🔧 Personnalisation

Pour modifier la page de présentation :
1. Éditer `docs/booktune_presentation.html`
2. Commiter les changements
3. GitHub Pages se mettra à jour automatiquement

## 📞 Support

En cas de problème avec GitHub Pages :
- Vérifier que le repository est public
- Attendre 5-10 minutes après la configuration
- Vider le cache du navigateur (Ctrl+F5)
- Contacter le support GitHub si nécessaire
