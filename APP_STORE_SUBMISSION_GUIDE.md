# 📋 GUIDE SOUMISSION APP STORES - BOOKTUNE

## 🎯 CHECKLIST SOUMISSION GOOGLE PLAY

### **Étape 1 : Préparation Compte (1-2 jours)**
- ✅ Créer compte Google Play Console : https://play.google.com/console
- ✅ Payer frais d'inscription : 25\$ (unique)
- ✅ Configurer profil développeur
- ✅ Accepter termes et conditions

### **Étape 2 : Préparation App (3-5 jours)**
- ✅ **Bundle Android** : Générer APK/AAB signé
- ✅ **Store Listing** :
  - Titre court : "BookTune" (50 chars max)
  - Titre long : "BookTune - Audiobooks Player & Library"
  - Description courte : "Découvrez +15K livres audio gratuits avec ambiances sonores personnalisées"
  - Description complète : 4000 chars max
- ✅ **Graphismes** :
  - Icône app : 512x512 PNG
  - Feature Graphic : 1024x500 PNG
  - Screenshots : 8 images (1080x1920)
  - Promo Video : Optionnel (MP4 30s-2min)

### **Étape 3 : Configuration Technique**
- ✅ **Permissions** : Vérifier AndroidManifest.xml
- ✅ **API Level** : minSdkVersion 26 (Android 8.0)
- ✅ **Target SDK** : Dernière version disponible
- ✅ **ABIs** : armeabi-v7a, arm64-v8a, x86, x86_64

### **Étape 4 : Contenu & Conformité**
- ✅ **Privacy Policy** : URL vers politique RGPD
- ✅ **Content Rating** : PEGI 3 (tout public)
- ✅ **ADS** : Déclarer si utilisation pubs
- ✅ **Target Audience** : Tout âge

### **Étape 5 : Soumission & Publication**
- ✅ **Draft Release** : Créer version brouillon
- ✅ **Internal Testing** : Tests équipe (optionnel)
- ✅ **Beta Testing** : Tests utilisateurs (optionnel)
- ✅ **Production Release** : Soumettre validation
- ⏳ **Validation** : 2-7 jours ouvrés
- 🎉 **Publication** : Automatique après validation

## 🍎 CHECKLIST SOUMISSION APP STORE

### **Étape 1 : Préparation Compte (1-2 jours)**
- ✅ Créer compte Apple Developer : https://developer.apple.com
- ✅ Payer frais d'inscription : 99\$/an
- ✅ Configurer App Store Connect
- ✅ Générer certificats distribution

- ✅ **Archive iOS** : Build depuis Xcode

- ✅ **External Testing** : Beta tests utilisateurs (24-48h)

### **Étape 3 : App Store Connect Setup**
- ✅ **App Information** :
  - Name : "BookTune"
  - Subtitle : "Audiobooks Player & Library"
  - Description : Version localisée EN/FR
- ✅ **Screenshots** : 6-10 images par device (iPhone/iPad)
- ✅ **Icons** : App Icon 1024x1024
- ✅ **Keywords** : audiobook, audio, livre, lecture

### **Étape 4 : Conformité Apple**
- ✅ **Guidelines Review** : Vérifier App Store Review Guidelines
- ✅ **Privacy** : Formulaire confidentialité détaillé
- ✅ **Purchases** : Configuration achats in-app
- ✅ **Ratings** : Classification contenu (4+)

- ✅ **Prepare for Submission** : Remplir tous champs
